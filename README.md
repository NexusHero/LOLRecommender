# LoL Coach

An AI-powered in-game item coaching assistant for League of Legends. A local Node.js bridge reads live game data from the Riot Games Live Client API and pushes real-time item recommendations to a Flutter mobile app over WebSocket.

Recommendations are generated by a heuristic engine (instant, no internet required) and optionally enriched by Claude (Anthropic) for natural-language explanations.

```

│                                                          │
│  LoL Client  ──►  Riot Live Client API (port 2999)       │

│          │  LlmExplainer (Claude API)      │             │
│          │  WebSocket Server (port 8765)   │             │

                            │  WebSocket (LAN)

              ┌─────────────────────────┐

              │  Live scoreboard        │
              │  Item recommendations   │
              │  AI explanations        │

```

## Prerequisites

- Node.js 18+
- Flutter SDK 3.4+
- League of Legends installed (the bridge reads from the local Live Client API)
- An Anthropic API key (optional — the heuristic engine works without it)

## Setup

### 1. Bridge

```bash
cd bridge
npm install
```

Create a `.env` file in `bridge/`:

```env
# Your in-game summoner name (used to identify your player in the data)
SUMMONER_NAME=YourSummonerName

# Optional: enables AI explanations via Claude
ANTHROPIC_API_KEY=sk-ant-...

# Optional: change the WebSocket port (default: 8765)
# WS_PORT=8765
```

### 2. Flutter app

```bash
cd flutter_app
flutter pub get
```

## Running

### Start the bridge

```bash
cd bridge
npm run dev        # development (watch mode)
npm start          # production (requires npm run build first)
```

The bridge will wait for an active League of Legends game. Once detected, it starts pushing game state and recommendations over WebSocket.

### Start the Flutter app

```bash
cd flutter_app
flutter run
```

Enter the local IP address of the PC running the bridge (e.g. `192.168.1.100`) and port `8765`. Both devices must be on the same network.

## How it works

1. **Polling** — The bridge polls `https://127.0.0.1:2999/liveclientdata/allgamedata` every second.
2. **Event detection** — `EventDetector` compares consecutive snapshots and emits events: `GAME_STARTED`, `ITEM_PURCHASED`, `LEVEL_UP`, `GAME_TICK`.
3. **Recommendations** — On `GAME_STARTED` and `ITEM_PURCHASED`, the heuristic engine builds a `CompProfile` from enemy champions and recommends counter-items.
4. **AI explanation** — If an Anthropic API key is set and the 60-second cooldown has elapsed, `LlmExplainer` calls Claude to generate a natural-language explanation. The system prompt is prompt-cached to reduce token costs by ~80% on repeated calls.
5. **WebSocket broadcast** — All events and recommendations are pushed to connected Flutter clients as JSON.

## Project structure

```
lolclient/
├── bridge/
│   ├── src/
│   │   ├── types.ts          # Zod schemas + TypeScript types
│   │   ├── poller.ts         # Live Client API polling
│   │   ├── parser.ts         # Raw data → ParsedGameState
│   │   ├── eventDetector.ts  # State-change event detection
│   │   ├── heuristic.ts      # Rule-based item recommendations
│   │   ├── llmExplainer.ts   # Claude API integration
│   │   ├── wsServer.ts       # WebSocket server
│   │   └── index.ts          # Entry point / DI wiring
│   └── src/__tests__/        # Jest unit tests (47 tests)
│
└── flutter_app/
    ├── lib/
    │   ├── models/           # Data models (one class per file)
    │   ├── services/         # WsService (ChangeNotifier)
    │   ├── screens/          # HomeScreen
    │   └── widgets/          # ConnectionForm, GameView
    └── test/                 # Flutter unit tests
```
