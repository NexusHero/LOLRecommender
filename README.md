# LoL Coach

An AI-powered in-game item coaching assistant for League of Legends. A local Node.js bridge reads live game data from the Riot Games Live Client API and pushes real-time item recommendations to a Flutter mobile app over WebSocket.

Recommendations are generated by a heuristic engine (instant, no internet required) and optionally enriched by an LLM (Claude, OpenAI, or Gemini) for natural-language explanations.

## Prerequisites

- Node.js 18+
- Flutter SDK 3.4+
- League of Legends installed (the bridge reads from the local Live Client API)

## Setup

### 1. Bridge

```bash
cd bridge
npm install
```

Start the bridge:
```bash
npm run dev        # development (watch mode)
npm start          # production (requires npm run build first)
```

The bridge will wait for an active League of Legends game. Once detected, it starts pushing game state and recommendations over WebSocket.

### 2. Flutter app

```bash
cd flutter_app
flutter pub get
flutter run
```

When you launch the app, go to the **Settings** tab. Here you can configure:
- Your Summoner Name
- The Bridge IP and Port (default `127.0.0.1:8765`)
- Your LLM Provider (None, Claude, OpenAI, or Gemini) and API Key

The app uses `shared_preferences` to persist these settings locally. Once connected, it will auto-switch to the **Coach** tab.

## How it works

1. **Polling** — The bridge polls `https://127.0.0.1:2999/liveclientdata/allgamedata` every second.
2. **Event detection** — `EventDetector` compares consecutive snapshots and emits events.
3. **Recommendations** — On `GAME_STARTED` and `ITEM_PURCHASED`, the heuristic engine builds a `CompProfile` from enemy champions and recommends counter-items.
4. **State Minification** — Before sending data to the LLM, the `StateMinifier` reduces the payload size (tokens) by stripping irrelevant game data.
5. **AI explanation** — If an LLM provider is selected, the bridge generates a natural-language explanation with a cooldown.
6. **WebSocket broadcast** — All events and recommendations are pushed to connected Flutter clients as JSON.

## Project structure

```
LOLRecommender/
├── bridge/                   # Backend (Node.js/TypeScript)
│   ├── src/
│   │   ├── types.ts          # Zod schemas + TypeScript types
│   │   ├── poller.ts         # Live Client API polling
│   │   ├── parser.ts         # Raw data → ParsedGameState
│   │   ├── eventDetector.ts  # State-change event detection
│   │   ├── stateMinifier.ts  # Token optimization for LLM
│   │   ├── heuristic.ts      # Rule-based item recommendations
│   │   ├── llmProvider.ts    # AI Factory (Claude, OpenAI, Gemini)
│   │   ├── wsServer.ts       # WebSocket server
│   │   └── index.ts          # Entry point / DI wiring
│   └── src/__tests__/        # Jest unit tests + Integration tests
│
├── flutter_app/              # UI (Flutter Desktop)
│   ├── lib/
│   │   ├── models/           # Data models
│   │   ├── services/         # WsService (ChangeNotifier)
│   │   ├── screens/          # MainScreen, HomeScreen (Coach Tab)
│   │   └── widgets/          # ConnectionForm, GameView
│   └── test/                 # Flutter UI and Unit tests
│
└── deployment/               # Build & packaging scripts
    ├── build_unix.sh         # macOS + Linux build script
    └── build_installer.ps1   # Windows MSIX build script
```
